# PicMap

Приложение для создания маршрутов путешествий и формирования воспоминаний.

## Стек

- Backend: Go + Gin + PostgreSQL 17
- Frontend: Nuxt 4 + Nuxt UI
- Карта: Leaflet
- Миграции: golang-migrate
